# Campagna Paolo & Federica

Sito statico (HTML + CSS + JS), nessuna installazione e nessun backend.

File: index.html, style.css, script.js, motivi.js (i 100 motivi), manifesto.png (immagine originale).

## Aprirlo in locale
Doppio clic su index.html (funziona in Safari, Chrome, Edge, Firefox).

## Pubblicarlo su Vercel
1. Vai su vercel.com e accedi.
2. "Add New..." > "Project" e scegli di caricare/importare la cartella (oppure: `npm i -g vercel`, poi `vercel` dentro la cartella).
3. Framework Preset: "Other", nessun build command. Deploy.
